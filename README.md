## 🚀 Como abrir o projeto

### Abrir com Dev Container

> **Observação:** A extensão **Dev Containers** precisa estar instalada no VS Code para este procedimento funcionar.

1. Instale o Docker, o Docker Compose e o VS Code para desktop. No VS Code,
   abra a aba **Extensões**, procure por **Dev Containers**
   (`ms-vscode-remote.remote-containers`) e instale a extensão.
2. Inicie o Docker e abra a pasta do projeto no VS Code.
3. Pressione **F1** e selecione **Dev Containers: Reopen in Container**
   (**Dev Containers: Reabrir no Contêiner**).
4. Aguarde a inicialização do ambiente. O servidor de desenvolvimento inicia
   automaticamente na porta `8080`.
5. Abra `http://localhost:8080` no navegador.

As alterações no código atualizam o site automaticamente.
